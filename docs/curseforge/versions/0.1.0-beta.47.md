<h2>v0.1.0-beta.47</h2>

<h3>Added</h3>

<ul>
<li><strong>Better Villager Animations villager dialogue (708 lines)</strong>: that mod shows
speech-bubble text above villagers (greetings, ambient small talk, trade banter) that was entirely
in English &mdash; not Minecraft translation keys, but text hardcoded in the mod's own Java
bytecode, so no <code>lang/es_es.json</code> could translate it. Adds
<code>assets/bettervillageranimations/dialogue/es_es.json</code>, an English&rarr;Spanish lookup
table (not a standard <code>lang.json</code>) consumed at runtime by a new mixin in the
<strong>Utility Nexus Fixes</strong> mod (v1.1.0+). The mod's own placeholder tokens
(<code>{player}</code>, <code>{speaker_goods}</code>, <code>{speaker_station}</code>,
<code>{speaker_task}</code>, <code>{listener_goods}</code>, <code>{listener_station}</code>,
<code>{listener_task}</code>, <code>{time}</code>, <code>{weather}</code>) are preserved literally
in the translation so the mod substitutes them normally. Only takes effect when both
<strong>Utility Nexus Fixes</strong> 1.1.0+ and <strong>Better Villager Animations</strong> are
installed and the client language is <code>es_es</code>; otherwise the original English text shows
unchanged.</li>
</ul>
