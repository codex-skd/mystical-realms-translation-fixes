<h2>v1.0.1 - Translation gap fix after modpack update</h2>

<p>The modpack updated several mod jars since release 1.0.0, introducing new English strings
(new config options, tooltips, items) that this pack did not cover yet. A full audit &mdash;
comparing every installed mod jar's <code>en_us.json</code> against the mod's own
<code>es_es.json</code> plus this resourcepack's overlay &mdash; found 155 new untranslated keys
across 13 namespaces. This release closes that gap. No other content changes.</p>

<h3>Added</h3>

<ul>
<li><strong>5 new namespace overlays</strong> (previously had zero coverage in this pack):
<code>bountiful</code>, <code>fragmentum</code>, <code>patchouli</code>, <code>yungsapi</code>,
<code>apotheosis</code>.</li>
<li><strong>8 existing overlays completed</strong> with their missing keys: <code>moonlight</code>,
<code>sophisticatedcore</code>, <code>xaeroworldmap</code>, <code>everycomp</code>,
<code>aquamirae</code>, <code>kaelos_gems</code>, <code>supplementaries</code>,
<code>just_in_nether</code>.</li>
</ul>

<p>Re-audit after the fix confirms full <code>es_es</code> coverage: 131/131 namespaces across the
current modpack's installed mods with no missing keys.</p>
