<h2>v1.0.0 - First stable release</h2>

<p>After 48 beta releases (2026-09-02 &rarr; 2026-09-15), validated in the live translation instance
and working correctly in the modpack, this project graduates to a stable <strong>release</strong>.
No content changes from beta.48 &mdash; same <code>es_es</code> translations and asset fixes, only
the version number and CurseForge release type change.</p>

<h3>Current scope</h3>

<ul>
<li><strong>89 mod namespaces</strong> with Spanish (<code>es_es</code>) translations, ~15,300 keys
total, merged on top of whatever Spanish each mod already ships.</li>
<li><strong>Better Villager Animations dialogue overlay</strong> (708 lines): in-game speech-bubble
text over villagers, translated via a companion mixin in <code>utility_nexus_fixes</code> 1.1.0+.</li>
<li><strong>Asset fix</strong>: Butchery's orphan <code>ravager_carcass</code> model (invalid element
rotation) replaced with the mod's own already-fixed sibling model, silencing a startup log error.</li>
</ul>

<blockquote>See the full per-batch history (mod-by-mod key counts, glossary decisions, QA passes) in
<code>CHANGELOG.md</code> of the repository, entries <code>0.1.0-beta.1</code> through
<code>0.1.0-beta.48</code>.</blockquote>
