<h2>v0.1.0-beta.48</h2>

<p>The modpack was updated (<strong>5.134.4 &rarr; 5.144.21</strong>, 164 mod jars instead of 158) and
brought in new mods with no Spanish translation. This release adds <code>es_es</code> for the 3 new
namespaces that actually ship text.</p>

<h3>Added &mdash; 3 new Spanish translations</h3>

<ul>
<li><strong>Hexerei</strong> (<code>hexerei</code>, 1070 keys): witchcraft/folk-magic mod &mdash;
cauldrons, brooms, familiars, hexes, herbs, rituals.</li>
<li><strong>Apothic Ascension</strong> (<code>apothic_ascension</code>, 627 keys): gear
ascension/upgrade addon for Apotheosis. Terminology matches the existing
<code>apotheosis</code> / <code>apothic_attributes</code> / <code>apothic_enchanting</code>
translations already in this pack.</li>
<li><strong>Kaelos Gems</strong> (<code>kaelos_gems</code>, 241 keys): new gem set for the
Apotheosis gem system.</li>
</ul>

<h3>Notes</h3>

<ul>
<li>4 other new namespaces from this modpack update (<code>better_connections</code>,
<code>integrated_cataclysm</code>, <code>waystone_towers</code>, <code>wover-preset</code>) ship an
empty <code>en_us.json</code> &mdash; nothing to translate.</li>
<li>Keys and every <code>%s</code> / <code>%d</code> / <code>\n</code> placeholder unchanged; key
count and order verified to match each mod's source file.</li>
<li>Translated with OpenCode (MiMo-V2.5 for Hexerei and Apothic Ascension; DeepSeek V4.1 Flash pilot
for Kaelos Gems) against <code>docs/GLOSARIO_ES.md</code> and, for Apothic Ascension, the existing
Apothic family translations for terminology consistency.</li>
</ul>
